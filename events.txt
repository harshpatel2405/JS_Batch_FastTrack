JAVASCRIPT IMPORTANT EVENTS — COMPLETE NOTES

==================================================
1. click
==================================================

Work:
Fires when the user clicks an element once.

Code:
button.addEventListener("click", function() {
    console.log("Button clicked");
});

Layman Example:
Like pressing a doorbell once.


==================================================
2. dblclick
==================================================

Work:
Fires when the user double-clicks an element.

Code:
button.addEventListener("dblclick", function() {
    console.log("Double clicked");
});

Layman Example:
Double-clicking a file to open it.


==================================================
3. mousedown
==================================================

Work:
Fires when the mouse button is pressed down.

Code:
button.addEventListener("mousedown", function() {
    console.log("Mouse button pressed");
});

Layman Example:
Pressing a doorbell but not releasing it yet.


==================================================
4. mouseup
==================================================

Work:
Fires when the mouse button is released.

Code:
button.addEventListener("mouseup", function() {
    console.log("Mouse button released");
});

Layman Example:
Releasing the doorbell after pressing it.

Layman Example:

7. mouseover
==================================================

Fires when the mouse pointer moves onto an element or one of its descendants.

Code:

    console.log("Mouse over");
});

Layman Example:
Moving your hand over a table and then over objects placed on the table.

IMPORTANT:
mouseover bubbles.


==================================================

==================================================

Fires when the mouse pointer leaves an element or moves to another element/descendant.

Code:

    console.log("Mouse out");
});

Layman Example:
Moving your hand away from a table/object.

IMPORTANT:
mouseout bubbles.


==================================================
9. keydown
==================================================

Work:
Fires when a keyboard key is pressed down.

Code:

    console.log(event.key);
});

Layman Example:
Pressing the "A" key.


==================================================
10. keyup
==================================================

Work:
Fires when a keyboard key is released.

Code:
document.addEventListener("keyup", function(event) {

});

Layman Example:
Releasing the "A" key after pressing it.


==================================================
11. input
==================================================

Work:
Fires whenever the value of an input changes while the user is entering data.

Code:
input.addEventListener("input", function(event) {
    console.log(event.target.value);
});

Example:
Typing:

H
Ha
Har
Hars
Harsh

The event can fire for every change.

Layman Example:
A teacher watching what a student writes character by character.


==================================================
12. change
==================================================

Work:
Fires when the value/state of a form element changes and the change is committed.

Code:
select.addEventListener("change", function(event) {
    console.log(event.target.value);
});

Layman Example:
Selecting a different country from a dropdown.

IMPORTANT:
For text inputs, change usually fires after the user finishes editing
(often when the input loses focus).

For select, checkbox, and radio controls, it fires when the selection/state changes.


==================================================
13. submit
==================================================

Work:
Fires when a form is submitted.

Code:
form.addEventListener("submit", function(event) {
    event.preventDefault();
    console.log("Form submitted");
});

Layman Example:
Clicking "Register" after filling a registration form.

IMPORTANT:
event.preventDefault()
stops the browser's default form submission.

==================================================
IMPORTANT INTERVIEW DIFFERENCES
==================================================

click vs dblclick
------------------
click     = one click
dblclick  = double click


mousedown vs mouseup
--------------------
mousedown = mouse button pressed
mouseup   = mouse button released


mouseenter vs mouseover
-----------------------
mouseenter = pointer enters element
mouseover  = pointer enters element/descendant

mouseenter does NOT bubble.
mouseover DOES bubble.


mouseleave vs mouseout
----------------------
mouseleave = pointer leaves element
mouseout   = pointer leaves element/descendant

mouseleave does NOT bubble.
mouseout DOES bubble.


keydown vs keyup
----------------
keydown = key pressed
keyup   = key released


input vs change
---------------
input  = fires while value is changing
change = fires when the change is committed


DOMContentLoaded vs load
------------------------
DOMContentLoaded = DOM/HTML is ready
load              = page resources are loaded


focus vs blur
-------------
focus = element gets focus
blur  = element loses focus


preventDefault vs stopPropagation
----------------------------------
preventDefault()
= stops the browser's default action

stopPropagation()
= stops event propagation


==================================================
EVENT FLOW
==================================================

When an event occurs, it can travel through 3 phases:

1. CAPTURING PHASE
2. TARGET PHASE
3. BUBBLING PHASE

Example:

Grandparent
    |
  Parent
    |
  Child  <-- CLICK


CAPTURING:

Grandparent
     ↓
Parent
     ↓
Child


TARGET:

Child


BUBBLING:

Child
     ↑
Parent
     ↑
Grandparent


==================================================
EVENT LISTENER
==================================================

Basic syntax:

element.addEventListener("event", function() {
    // code
});


Example:

button.addEventListener("click", function() {
    console.log("Clicked");
});


==================================================
IMPORTANT addEventListener OPTIONS
==================================================

Capture:

element.addEventListener("click", handler, true);

true = capturing phase


Bubble:

element.addEventListener("click", handler, false);

false = bubbling phase

Default:

element.addEventListener("click", handler);

Default is bubbling.


Options object:

element.addEventListener("click", handler, {
    capture: true,
    once: true
});


once: true
= listener runs only once.


==================================================
EVENT TARGET vs CURRENTTARGET
==================================================

event.target
-------------
The actual element that started the event.

event.currentTarget
-------------------
The element whose event listener is currently executing.


Example:

parent.addEventListener("click", function(event) {

    console.log(event.target);
    console.log(event.currentTarget);

});


If button is clicked:

event.target
= button

event.currentTarget
= parent


==================================================
EVENT DELEGATION
==================================================

Event delegation means:

Instead of adding event listeners to many children,
add ONE listener to their common parent.


Example:

<div id="menu">

    <button id="home">Home</button>
    <button id="about">About</button>
    <button id="contact">Contact</button>

</div>


JavaScript:

const menu = document.getElementById("menu");

menu.addEventListener("click", function(event) {

    if (event.target.id === "home") {
        console.log("Home clicked");
    }

    if (event.target.id === "about") {
        console.log("About clicked");
    }

    if (event.target.id === "contact") {
        console.log("Contact clicked");
    }

});


Why does this work?

Because:

Button
   ↓
click happens
   ↓
event bubbles
   ↓
Parent receives event
   ↓
event.target tells us which button was clicked


Mental Model:

MANY CHILDREN
      ↓
ONE PARENT LISTENER
      ↓
EVENT DELEGATION


==================================================
STOPPING EVENT PROPAGATION
==================================================

Use:

event.stopPropagation();


Example:

child.addEventListener("click", function(event) {

    console.log("Child");

    event.stopPropagation();

});


This prevents the event from continuing to parent elements.


==================================================
STOP IMMEDIATE PROPAGATION
==================================================

Use:

event.stopImmediatePropagation();


Difference:

stopPropagation()
= stops event from moving to other elements.

stopImmediatePropagation()
= also stops other listeners on the same element.


==================================================
MOST IMPORTANT CONCEPT
==================================================

EVENT PROPAGATION:

The browser moves ONE event through the DOM.

It is NOT:

Child calls Parent
Child calls Grandparent

It IS:

Browser creates an event
        ↓
Browser follows DOM event path
        ↓
Capturing phase
        ↓
Target phase
        ↓
Bubbling phase


FINAL MEMORY TRICK:

CAPTURE = TOP → BOTTOM

BUBBLE = BOTTOM → TOP

DELEGATION = ONE PARENT HANDLES MANY CHILDREN
